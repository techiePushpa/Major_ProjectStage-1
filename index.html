Problem

The model got safer. The stack around it didn't.

Prompt injection is now a well-documented failure mode: adversarial input convinces a model to ignore its instructions, leak secrets, or produce something it shouldn't. The vulnerability rarely lives in the model weights — it lives in everything wired up around them.

Enterprises don't just send text anymore. Voice recordings and uploaded images carry the same risks — and a few new ones. A gateway built for one modality doesn't protect the other two.

Defense layers

Four coordinated layers, one pipeline

flagged
01

Prompt & content firewall

Filters incoming text and transcribed audio for jailbreak and injection patterns. Checks attached images and requested edits against content safety rules before anything else runs.

redacted
02

PII & sensitive data sanitization

Detects personal or secret information in text, transcripts, or image text via OCR, and replaces it with placeholders before the LLM ever sees it.

routed
03

Multi-agent orchestration

Classifies intent and modality, performs redaction and normalization, routes to the correct model — LLM, ASR, or vision — and coordinates every safety check along the way.

verified
04

Output validation

Scans every text, audio, and image response for unsafe instructions, hallucinated or toxic content, and sensitive leaks. Unsafe responses are filtered, regenerated, or rejected.

Models

Six specialized models, one coherent pipeline

No single model carries this system. Each one owns a narrow part of the pipeline.

Reasoning

Llama-3-8B

Core LLM — reasoning, summarization, and text generation.

Detection

Sentence-Transformers

Embeds prompts for injection similarity detection against known attack patterns.

Transcription

ASR (Whisper-class)

Converts voice input to text so the firewall and redaction pipeline apply uniformly.

Synthesis

Text-to-speech

Synthesizes voice replies from validated, already-safe LLM text.

Vision

Vision / image model

Understands images, generates descriptions, and supports allowed edits.

Safety

Content safety models

Detects sexual, violent, hateful, or self-harm content across text and images alike.
